Build a console-based inventory management system for a small shop that uses the full power of the Java Collections Framework and Generics. The system manages products organized by category, supports multiple sort orders, finds duplicates, tracks low-stock items using a PriorityQueue, and generates summary reports using Maps. Every data structure choice is deliberate — you will use the right collection for each job and be able to explain why. This project ties together List, Set, Map, Queue, Comparable, Comparator, and Generics in one cohesive application.
